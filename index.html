Commit " + commitMsg + " pushed successfully."); } } package com.tcs.git; public interface OutputListener { void log(String message); } public static String run(File repo, OutputListener out, String... args) throws Exception { ProcessBuilder pb = new ProcessBuilder(buildCommand(args));
