1. If the field 'Type of Delivery' has a value as 'Fixed', 'TOM', 'Spot' then value under this field will be same as in the field 'Date of Expiry' and field will be read only 2. If the field 'Type of Delivery' has a value as 'Option' then, this field will become mandatory to input date by the user. user should not able to capture the value earlier than the system date. Start date should not be earlier than the system date. 3. If the field 'Type of Delivery' has a value as 'Tom' then, value under this field will be 'System Date + Next Working Day'.In case next day is holiday then next working day to be considered. In this case this field will be read only.. 4. If the field 'Type of Delivery' has a value as 'Spot' then, value under this field will be 'system Date + 2 days' In case 2nd day is holiday, then next working day to be considered. In this case this field will be read only. 5. If user captures the date earlier than the syatem date then there will be error notification that 'Start Date cannot be less than today's date'. 6. Both Expiry Date and Start Date are to be validated in terms of Indian working days as well as the currency business days.
